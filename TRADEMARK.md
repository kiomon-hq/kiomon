# Trademark

The **Apache-2.0 licence in [`LICENSE`](LICENSE) covers the code in this repository. It
does not cover the Kiomon name or logo** — no open-source licence grants trademark rights,
and Apache-2.0 §6 says so explicitly.

That is a narrow reservation, not a restriction on use:

## You may, without asking

- Use, modify, and redistribute this software commercially or otherwise.
- Say that your product or project **works with `kiomon`**, **is built on `kiomon`**, or
  **is a fork of `kiomon`** — including in a package name such as `kiomon-plugin-x` or
  `x-for-kiomon`, as long as the name does not suggest the project is *ours*.
- Keep the name in a fork, provided the README says prominently that it is a fork and links
  to this repository.
- Use the name in articles, talks, courses, and benchmarks.

## Please ask first

- Naming a product, service, company, or hosted offering **Kiomon** or something confusingly
  close to it — including a domain name or a cloud version of this engine.
- Using the logo in a way that suggests endorsement, sponsorship, or official status.
- Distributing a modified build under the `kiomon` name without saying it is modified.

Requests go to **hello@kiomon.com**, and the answer is normally yes.

## Why this exists

A memory engine's name is how people find the real thing. The hosted product at
[kiomon.com](https://kiomon.com) is a separate, commercial service; if a modified fork of
this engine were distributed as "Kiomon", users would have no way to tell which behaviour,
which data handling, and which support promise they were getting. The licence already lets
you do everything you would want with the code — the trademark policy only makes sure the
name keeps pointing at one thing.
